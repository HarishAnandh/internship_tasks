4. Main.java

Let's make the example slightly more useful by saving and retrieving the student.

src/main/java/com/example/Main.java



Main.java







package com.example;



import org.hibernate.Session;

import org.hibernate.SessionFactory;

import org.hibernate.cfg.Configuration;



public class Main {



public static void main(String[] args) {



// Create SessionFactory

SessionFactory factory = new Configuration()

.configure()

.buildSessionFactory();



// Open Session

Session session = factory.openSession();



// Start transaction

session.beginTransaction();



// Create Student

Student student = new Student(1, "Rahul", 20);



// Save Student

session.persist(student);



// Commit

session.getTransaction().commit();



System.out.println("Student saved!");



// Retrieve Student

session = factory.openSession();



Student result = session.get(Student.class, 1);



System.out.println("Student ID: " + result.getId());

System.out.println("Student Name: " + result.getName());

System.out.println("Student Age: " + result.getAge());



// Close

session.close();

factory.close();

}

}

now what did we create

We built a fully functional Java application that uses Hibernate ORM to connect to an H2 in-memory database, all managed using Maven inside VS Code.

Here is a breakdown of the exact pieces we created to make it work:

1. The Project Structure & Build Tool (pom.xml)
What it is: The Maven configuration file.

What it does: It tells Maven what libraries (dependencies) to download. We added Hibernate Core (to handle database operations using Java objects) and the H2 Database (a lightweight, fast database that lives entirely in your computer's memory while the program runs).

2. The Entity Class (Student.java)
What it is: A standard Java class mapped to a database table using annotations.

What it does: Using annotations like @Entity, @Id, and @Table, this class tells Hibernate: "Whenever I create a Student object in Java, turn it into a row inside a database table named Student."

3. The Configuration File (hibernate.cfg.xml)
What it is: The Hibernate configuration file.

What it does: It holds the connection details—telling Hibernate to use the H2 in-memory database driver (org.h2.Driver), connect to jdbc:h2:mem:studentdb, and automatically create or update database tables (hbm2ddl.auto).

4. The Main Execution File (Main.java)
What it is: The entry point of your Java program.

What it does:

Sets up the Hibernate SessionFactory.

Creates a new Student object (Rahul, age 20).

Opens a Hibernate Session and saves the student (session.save() or persist()), which triggered the SQL INSERT statement you saw in the terminal.

Queries the database back to fetch the student and print out their details (Student ID: 1, Student Name: Rahul, etc.).

Switching from an H2 in-memory database to MySQL is a great next step! Because we are using Hibernate, your Java code (Student.java and Main.java) won't need to change at all—Hibernate handles the database translation for us.

We only need to change two configuration files: pom.xml (to add the MySQL driver) and hibernate.cfg.xml (to point to your local MySQL server).

Step 1: Add the MySQL Dependency to pom.xml
Open your pom.xml file and add the MySQL connector dependency inside the <dependencies> block:

XML
<!-- MySQL Connector -->
<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <version>8.3.0</version>
</dependency>
Step 2: Update hibernate.cfg.xml
Open your src/main/resources/hibernate.cfg.xml file and replace the H2 properties with your MySQL connection details:

XML
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE hibernate-configuration PUBLIC
        "-//Hibernate/Hibernate Configuration DTD 3.0//EN"
        "http://www.hibernate.org/dtd/hibernate-configuration-3.0.dtd">
        
<hibernate-configuration>
    <session-factory>
        <!-- MySQL Connection Settings -->
        <property name="connection.driver_class">com.mysql.cj.jdbc.Driver</property>
        <property name="connection.url">jdbc:mysql://localhost:3306/studentdb?useSSL=false&amp;serverTimezone=UTC</property>
        <property name="connection.username">root</property>
        <property name="connection.password">YOUR_MYSQL_PASSWORD</property>

        <!-- Hibernate Settings -->
        <property name="hibernate.show_sql">true</property>
        <property name="hibernate.hbm2ddl.auto">update</property>

        <!-- Registered Entity Class -->
        <mapping class="com.example.Student"/>
    </session-factory>
</hibernate-configuration>
(Note: Replace YOUR_MYSQL_PASSWORD with your actual MySQL root password, or leave it blank "" if you don't have one).

can we do some more crud operations

Yes, absolutely! Now that Hibernate and MySQL are connected, performing CRUD (Create, Read, Update, Delete) operations is very clean because Hibernate manages the database changes automatically through Java objects.

Since your project uses Hibernate 6, we use modern methods like persist() (for create), find() (for read), and remove() (for delete).

Step-by-Step Full CRUD in Main.java
Replace the code inside your src/main/java/com/example/Main.java with the following comprehensive example:

Java
package com.example;

import org.hibernate.Session;
import org.hibernate.SessionFactory;
import org.hibernate.Transaction;
import org.hibernate.cfg.Configuration;

public class Main {
    public static void main(String[] args) {
        // 1. Create SessionFactory
        SessionFactory factory = new Configuration().configure("hibernate.cfg.xml").addAnnotatedClass(Student.class).buildSessionFactory();
        
        Session session = factory.openSession();
        Transaction tx = null;

        try {
            // ==========================================
            // 1. CREATE (Insert a new student)
            // ==========================================
            tx = session.beginTransaction();
            Student student = new Student(1, "Rahul", 20);
            session.persist(student); // Saves the student
            tx.commit();
            System.out.println("--> CREATE: Student saved successfully!");

            // ==========================================
            // 2. READ (Fetch the student from database)
            // ==========================================
            session.clear(); // Clear cache to force database read
            Student retrievedStudent = session.find(Student.class, 1);
            System.out.println("--> READ: Found Student -> Name: " + retrievedStudent.getName() + ", Age: " + retrievedStudent.getAge());

            // ==========================================
            // 3. UPDATE (Modify student's age)
            // ==========================================
            tx = session.beginTransaction();
            Student studentToUpdate = session.find(Student.class, 1);
            studentToUpdate.setAge(21); // Update age from 20 to 21
            session.merge(studentToUpdate); // Updates the record in MySQL
            tx.commit();
            System.out.println("--> UPDATE: Student age updated to 21!");

            // Verify update by reading again
            Student updatedStudent = session.find(Student.class, 1);
            System.out.println("--> READ AFTER UPDATE: Age is now " + updatedStudent.getAge());

            // ==========================================
            // 4. DELETE (Remove student from database)
            // ==========================================
            tx = session.beginTransaction();
            Student studentToDelete = session.find(Student.class, 1);
            if (studentToDelete != null) {
                session.remove(studentToDelete); // Deletes the record
                System.out.println("--> DELETE: Student removed from database.");
            }
            tx.commit();

        } catch (Exception e) {
            if (tx != null) tx.rollback();
            e.printStackTrace();
        } finally {
            session.close();
            factory.close();
        }
    }
}
